
# SF6MiniTraining

## 1. プロジェクト概要

### 1.1 アプリ名
SF6MiniTraining

### 1.2 概要
格闘ゲーム「Street Fighter 6」の基本的な反応力を鍛えるためのスマートフォン向けWebアプリケーション。

短い空き時間や移動時間、待ち時間などを利用して、手軽に反応トレーニングを行えることを目的とする。

### 1.3 開発目的
- 対空、差し返し、インパクト返しの反応力を鍛える。
- 短時間で繰り返し練習できる環境を提供する。
- 練習結果を記録し、自分の成長を確認できるようにする。

### 1.4 対象ユーザー
- Street Fighter 6をプレイしているユーザー
- 対空、差し返し、インパクト返しを練習したいユーザー
- スマートフォンで手軽に練習したいユーザー

## 3. 機能要件

### 3.1 ホーム画面

以下の機能を提供する。

- トレーニング開始ボタン
- 過去の練習結果の表示
- 最大連続成功数の表示

練習結果は直近5回分を表示する。

### 3.2 トレーニング機能

以下の3種類のトレーニングを提供する。

| トレーニング | 表示する動作 | 正解操作 |
|---|---|---|
| 対空 | 相手キャラクターのジャンプ | 対空 |
| 差し返し | 相手キャラクターの攻撃モーション | 差し返し |
| インパクト返し | ドライブインパクト | インパクト返し |

#### 3.2.1 動作の表示
- 3種類の動作からランダムに1種類を選択する。
- キャラクター風のアニメーションで動作を表示する。
- 動作の出現順序はランダムとする。

#### 3.2.2 回答操作
- 動作に対応した回答ボタンを表示する。
- ユーザーが回答ボタンをタップすると正誤判定を行う。

#### 3.2.3 正誤判定
- 正しいボタンを制限時間内に押した場合は成功とする。
- 間違ったボタンを押した場合は失敗とする。
- 制限時間内に回答できなかった場合は失敗とする。

#### 3.2.4 トレーニング終了条件
以下のいずれかを満たした場合、トレーニングを終了する。

- 成功数が99回に達した場合
- 失敗数が3回に達した場合

#### 3.2.5 カウント管理
- トレーニング開始時に成功数と失敗数を初期化する。
- 成功した場合は成功数を加算する。
- 失敗した場合は失敗数を加算する。
- 失敗した場合は連続成功数をリセットする。
- 最大連続成功数を記録する。

### 3.3 反応時間計測機能

- アニメーション開始時刻を記録する。
- 回答ボタンを押した時刻を記録する。
- 2つの時刻の差から反応時間を計算する。
- 反応時間をミリ秒単位で取得する。
- 60FPS換算でフレーム相当を計算する。

計算式：

```javascript
const reactionTime = endTime - startTime;
const frames = Math.round(reactionTime * 60 / 1000);
```

※ブラウザ上で計測するフレーム数は、実際のゲーム内フレームと完全には一致しないため、「フレーム相当」として扱う。

### 3.4 結果画面

トレーニング終了後、以下の情報を表示する。

- 成功数
- 失敗数
- 最大連続成功数
- 平均反応時間
- 平均フレーム相当
- もう一度練習するボタン
- ホームに戻るボタン

### 3.5 練習結果保存機能

練習結果をブラウザのlocalStorageに保存する。

保存する情報：

| 項目 | 内容 |
|---|---|
| 練習日時 | トレーニングを実施した日時 |
| 成功数 | 正解した回数 |
| 失敗数 | 間違えた回数 |
| 最大連続成功数 | 最も長く連続成功した回数 |
| 平均反応時間 | 平均反応時間（ms） |
| 平均フレーム相当 | 平均反応時間の60FPS換算値 |

保存件数は直近5回分をホーム画面に表示する。

## 5. 非機能要件

### 5.1 操作性
- スマートフォンで簡単に操作できること。
- ボタンはタッチしやすい大きさにする。
- 画面遷移を分かりやすくする。
- 余計な操作を減らし、短時間で練習を開始できること。

### 5.2 デザイン
- 集中して練習できる落ち着いたデザインとする。
- 過度に派手な色使いやアニメーションを避ける。
- 必要な情報を分かりやすく表示する。

### 5.3 レスポンシブ対応
- AndroidとiPhoneの画面サイズに対応する。
- 縦画面での表示を基本とする。
- 画面からボタンや文字がはみ出さないこと。

### 5.4 パフォーマンス
- 画面表示や操作に大きな遅延が発生しないこと。
- アニメーションを滑らかに表示すること。
- 不要な処理を減らすこと。

### 5.5 データ管理
- 練習結果はlocalStorageに保存する。
- ブラウザを再起動しても保存データを参照できること。
- ブラウザのデータ削除によって保存内容が消える可能性があることを考慮する。
- 初期バージョンでは端末間のデータ同期は行わない。

## 9. 今後決定する項目

開発開始前および実装中に、以下の仕様を確定する。

- 回答受付を開始するタイミング
- 1問あたりの回答制限時間
- 同じ動作が連続して出現することを許可するか
- 3種類の動作の出現確率
- 回答ボタンの配置
- アニメーションの再生時間
- 反応時間の計測基準
- 失敗時の表示内容
- 練習結果の保存件数
- 効果音の有無

## 10. 開発方針

まずはHTML・CSS・JavaScriptを使用して、ブラウザ単体で動作するトレーニングアプリを完成させる。

初期バージョンではゲーム本体との連携を行わず、アプリ内のアニメーションとタッチ操作で反応トレーニングを実施する。

その後、実際の利用状況や必要性に応じて、コントローラー入力取得やゲーム連携機能を追加する。
